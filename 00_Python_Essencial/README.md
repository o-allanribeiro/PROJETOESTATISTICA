# Módulo 00 — Python Essencial

> Status: 📋 Planejado

## Objetivo
Preparar a base de Python necessária para acompanhar todo o curso, para quem nunca programou ou está enferrujado. Sem este módulo, os módulos seguintes assumem que você já sabe ler e escrever código Python básico.

## Tópicos abordados
- Instalação e ambiente: Python, Jupyter Notebook / VS Code
- Tipos de dados, variáveis, estruturas de controle (`if`, `for`, `while`)
- Funções e organização de código
- `numpy`: arrays e operações vetorizadas
- `pandas`: `Series`, `DataFrame`, leitura de `.csv`/`.xlsx`, filtragem e agregação
- `matplotlib` / `seaborn`: gráficos básicos
- Boas práticas de notebook (organização, markdown, reprodutibilidade)

## Pré-requisitos
Nenhum. Este é o ponto de partida do curso.

## Ferramentas
`python`, `jupyter`, `numpy`, `pandas`, `matplotlib`, `seaborn`

## Por que este módulo existe
Todo o material original da graduação (Estatística I/II, Econometria I/II) foi trabalhado em planilhas Excel e no Gretl. Este módulo é a ponte que falta: dá a base de Python para reproduzir esses mesmos conceitos em código, que é a proposta deste repositório.
