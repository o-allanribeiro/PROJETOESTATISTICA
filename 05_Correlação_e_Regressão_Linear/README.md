# Módulo 05 — Correlação e Regressão Linear

> Status: 📋 Planejado

## Objetivo
Estudar a relação entre duas variáveis: primeiro medir essa relação (correlação) e depois modelá-la (regressão linear simples). Este módulo é a ponte direta para Econometria.

## Tópicos abordados
- Distribuição conjunta de duas variáveis
- Covariância
- Coeficiente de correlação de Pearson
- Regressão linear simples (método dos mínimos quadrados)
- Coeficiente de determinação (R²)
- Análise gráfica de resíduos

## Pré-requisitos
[Módulo 04 — Inferência Estatística](../04_Inferência_Estatística)

## Ferramentas
`numpy`, `scipy.stats`, `statsmodels`, `seaborn`

## Origem do conteúdo
Sílabo baseado nas aulas de distribuição conjunta e correlação/covariância de Estatística II, e nos exercícios de regressão linear resolvidos originalmente em planilha Excel — aqui reproduzidos em Python.
