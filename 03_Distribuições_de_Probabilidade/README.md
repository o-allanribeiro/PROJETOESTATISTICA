# Módulo 03 — Distribuições de Probabilidade

> Status: ✅ Completo

## Conteúdo
- [`variaveis_aleatorias_discretas.ipynb`](variaveis_aleatorias_discretas.ipynb) — valor esperado e variância de uma variável aleatória, Distribuição Binomial e Distribuição de Poisson, com exemplos aplicados (controle de qualidade, seguros, atendimento)
- [`variaveis_aleatorias_continuas.ipynb`](variaveis_aleatorias_continuas.ipynb) — Distribuição Uniforme, Exponencial, Normal e t de Student, com exemplos aplicados (envase, tempo de espera, prazos, amostras pequenas)

## Objetivo
Formalizar o conceito de variável aleatória e estudar as distribuições de probabilidade mais usadas em estatística aplicada e economia.

## Tópicos abordados
- Variável aleatória discreta x contínua
- Valor esperado, variância e desvio padrão de uma variável aleatória
- Distribuição Binomial
- Distribuição de Poisson
- Distribuição Uniforme
- Distribuição Exponencial
- Distribuição Normal
- Distribuição t de Student
